How the probability is calculated

Standardize each boundary using z = (x − μ)/σ. The area left of x is Φ(z). An interval uses the difference between the cumulative probabilities at its endpoints. Shading shows the visible part of the event. Histogram height equals count divided by sample size and bin width.
